# Sartori Lab website

Source of the lab website, served with GitHub Pages.

- `index.html`: the whole site (all pages, text and styling)
- `images/`: pictures used on the site
- `404.html`: sends old Squarespace links (like /apply) to the right section

To edit text, open `index.html` on GitHub, click the pencil icon, change the text and commit. The site updates within a minute or two.
